## 🎨 The design philosophy

A personal portfolio should be easy to explore without feeling lifeless.

This project brings together:

- **Clean layouts** that keep content readable.
- **Colorful visual elements** that give the interface personality.
- **Interactive details** that make navigation feel engaging.
- **Responsive styling** for desktop, tablet, and mobile screens.
- **Light and dark themes** for different viewing preferences.

The goal is simple: make the experience feel personal while keeping the work at the center.

## 🚀 Run it locally

Want to explore the code or experiment with the design?

### 1. Clone the repository

```bash
git clone https://github.com/myselfsneha/sneha-portfolio.git
```

### 2. Enter the project directory

```bash
cd sneha-portfolio
```

### 3. Open the portfolio

Open `index.html` in your browser.

No framework installation or build process is required for the basic HTML, CSS, and JavaScript setup.
